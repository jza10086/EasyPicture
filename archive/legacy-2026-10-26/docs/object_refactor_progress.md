## 第一阶段：统一事务与输入所有权

已交付 `PropertyBinding`、`PropertyEditSession`、`InteractionCoordinator` 和可注入指针后端。
文字、SVG、对象变换、图层透明度共享私有预览与一次提交；文本编辑按会话合并。
公共填充／描边、颜色弹窗和应用／取消区块供属性页与工具栏组合使用。
动态范围、模型反馈、目标切换与删除不会重建或重填活动字段。
拖动、文本和模态生命周期具备明确所有权；非法值、Esc、右键、窗口失活与版本冲突取消。

自动证据：`test_property_transactions.py`、`test_property_binding.py`、数值控件 UI 测试、
`test_object_workspace.py` 及颜色／描边／AI 面板测试。真实指针后端及原生捕获在测试中被禁止。
一次手势只提交一条历史，取消和无变化为零条；原生光标恢复与手感留给人工验收。

## 第二阶段：精确事件与增量 UI

已交付事务末尾 `DocumentChangeSet`、分类版本、Tile 集、旧／新边界及结构操作。
选择是工作区状态。名称与锁定保留像素缓存；局部像素只失效对应 Tile；
标签、树行和精灵缩略图增量更新，完成事务合并派生刷新。
选择、对象命令、输入、渲染和预览职责由公共组件承接，主窗口负责组合。
加入事件、帧请求、快照、源缓存和缩略图计数，以及固定场景基线。

大纲按 UUID 建立行索引。Qt 索引使用整数标识，避免删除／替换对象后的悬空 Python 地址。
Qt 行移除通知期间仍会查询旧行：锁定和权限从模型当前行树读取，不访问已删除的领域对象。
针对这个实际回归增加了删除通知期间查询、撤销、失效索引及强制垃圾回收测试。
窗口关闭取消并等待后台任务，工作线程在退出前释放自己创建的 Qt 渲染资源。

自动证据：`test_incremental_refresh.py`、`test_object_collections.py`、
`test_canvas_render_coordinator.py`，以及本文性能表。

## 第三阶段：统一对象与 v5

已交付递归混合 `Collection`、`RasterObject`、`TextObject`、`SvgObject`，
统一 UUID／父索引、根对象、空文档和纯矢量文档。集合无矩阵，继承显隐、锁定和穿透透明度。
`ObjectCommandService` 统一批量创建、复制、删除、移动、属性与矩阵更新；
复制使用新 UUID 和写时复制像素，不存在联动编辑。
栅格局部尺寸、Tile、矩阵、中心和采样方式进入快照及持久化；扁平栅格列表仅为派生查询。

最终格式只接受 schema v5，根和集合内部均可混合对象。删除旧迁移和自定义资源摘要路径。
原子保存、追加、恢复、图片／SVG／帧导出均使用新契约。
结构、引用、循环／重复 ID、路径、数值、大小和解码有效性由读取器检查。
旧版本和旧两级结构明确拒绝，不自动改写。

自动证据：`test_project_io.py`、`test_object_collections.py`、
`test_raster_object_transforms.py`、嵌入帧／追加／恢复与 SVG 测试。
对象、矩阵和像素数组直接比较；没有计算或校验文件／资源摘要。

## 第四阶段：大纲、模式和局部坐标

已交付带类型／锁定标记的大纲、搜索、多选、跨集合拖放、重命名、复制、删除和排序。
搜索只影响视图并禁用含糊拖放；选择按 UUID 保持，集合展开和工作区状态继续保存。
画布点选／框选与大纲共用选择。对象、像素、矢量编辑模式明确分开，选择不抢工具。
批量移动／旋转／缩放使用共同中心，可修改中心；锁定目标使整批操作拒绝。
文字与图形保持连续创建独立对象，保留基础几何和顶点编辑范围。

`RasterMapping` 捕获笔划目标与矩阵，笔刷、橡皮、桶、吸管、选区、图形、颜色处理、
调色板、描边和 AI 整理以对象局部网格工作。无选区可以编辑局部范围内的画布外像素。
对象矩阵操作不重采样；像素透视／浮动选区与应用对象变换是明确的像素操作。
画布裁切、缩小和透明修剪保留源像素；图像缩放调整矩阵；对象分辨率和局部裁切单独执行。
编辑视图对画布外内容使用 25% 透明度，图片／帧／Atlas 输出严格裁切到画布。

自动证据：仿射平移／旋转／非等比缩放／翻转后的笔划、选区、取样、填充、撤销和保存测试；
`test_object_pixel_operations.py` 覆盖分辨率、变换应用、画布外弱化和独立帧局部调整；
原有图形、透视、文字、顶点与多工作区测试已适配新语义。

## 第五阶段：缓存、预览和验收

已交付有预算的 SVG／文字、CPU Tile、GPU 页和缩略图缓存；变换保留源像素缓存。
空间索引用于裁剪和命中，边界包含描边。显示遍历结果按渲染相关版本复用。
`PreviewScheduler` 为每会话保留一个运行请求和一个最新待处理请求，
目标、工程、编辑文档、依赖版本及 generation 均需匹配才能应用结果。
颜色、描边、AI、调色板、重图形预览和 Tile 工作区使用该协议；预览与保存／恢复分队列。

大图常用颜色处理提供最长边 1024 的交互预览，随后计算完整结果；
低分辨率结果不能提交，应用时冻结参数，等待期间仍可取消。
抖动、精确描边、AI 整理维持完整结果原子替换。
新增完整结果等待、冻结参数和取消后迟到结果的 UI 回归。

### 性能对比

同一 Windows 主机、Python 3.14.3、Qt 6.11.1，QPainter／offscreen；固定生成数据，
每场景预热 2 次后采样 20 次。性能运行与完整测试分开，未并发压测。
第二阶段基线与当前均为整张输出尺寸的软件绘制，包含画布背景，不含导出编码。

超过 10% 的回归项为 128² 场景，绝对 P95 增加 0.070 ms。新增每对象矩阵、局部范围裁剪及
