# ADR-0036：精灵帧即 Tile、完整预览与整像素过渡

状态：Accepted，P10D 人工验收于 2026-08-30 通过。

P10D 不建立独立 Tile 像素模型。Tile A/B 始终引用当前工程已有精灵帧；linked 帧从源画布权威合成读取，detached 帧从嵌入文档权威合成读取。Tile 检查标签、A/B 选择、热力图和打开状态均为临时 UI 状态，不进入 `.limg`、撤销、缩略图或导出。仅工作区参数写入 QSettings。

接缝距离采用所选 RGB 或 RGBA 通道的最大绝对字节差。超过用户容差的位置视为不匹配，并生成匹配率、平均差值、最大差值及像素位置。循环偏移只使用整数环绕，不插值。预览表面每次以最新 generation 的完整临时文档替换，OpenGL 与软件后端共享同一权威 RGBA 输入，并保留用户缩放和中心。

过渡固定为硬切或 Bayer 4×4 有序抖动。有序抖动只在过渡带内选择 A 或 B 的完整 straight RGBA 像素，不混合通道，因此不会引入新颜色、半透明中间值或隐藏 RGB 损失。生成结果保存为未分组 detached 精灵帧，一条撤销命令同时创建/删除帧定义及其嵌入文档；原 Tile 永不被修改。

`.limg` 继续使用 schema v4。自动地形规则、Wang Tile、TileMap、接缝自动修复、批量过渡、碰撞轮廓及引擎专用 TileSet 不属于 P10D。

## 后台与内存边界（2026-08-30）

预览模式收敛为平铺、相邻对比和过渡预览。平铺统一采用整数循环偏移再重复的路径（零偏移覆盖普通平铺），不再提供独立的“循环偏移”模式入口。旧界面设置中的 `repeat` 回落到 `offset`；此字段不进入工程文件。属性行按模式整体显隐，不清空已输入参数；平铺仅依赖 Tile A，隐藏的 Tile B 不参与读取或结果校验。

边长超过 1024 或面积超过 32768 像素的 Tile 使用串行 JobRunner。工作线程只读取主线程捕获的快照，合成、接缝分析、过渡、热力图段与临时文档均在后台准备。一个运行任务加一个最新待处理请求，不积压中间参数。generation、工程 UUID、A/B 帧 UUID 和源 revision 共同校验结果，切换工程/表面、取消或删帧后不得回写旧结果。

参数变化保留上一完整画面，最新结果到达时一次替换；生成独立帧只接受与当前参数及 revision 一致的已完成结果。大过渡按 64 行检查取消。内容签名只覆盖选中帧，改名、动画顺序以及不相交栅格 Tile 的变化不重新合成原像素。

平铺直接构造 display-only Tile 映射，重复块共享只读缓冲区，不先生成完整巨幅 RGBA。临时 Tile 文档允许最多 5×8192 的逻辑显示边界；真实工程和可保存的独立帧仍限制为 8192，schema 和载入校验不变。普通写入仍为 copy-on-write，临时表面不进入父工程、保存或导出。

热力图使用固定 3 屏幕像素宽度的整数条带，消除软件/OpenGL 对 cosmetic pen 的半像素差异。诊断截图分别检验像素合成和绘制完成后的 Overlay，不把热力图误作源像素。
