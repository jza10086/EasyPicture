# ADR-0029：SVG 导出、栅格嵌入与矢量栅格化

## 状态

Accepted for P9B.

## 决策

SVG 导出固定为静态单文档，尺寸与画布一致。栅格组使用 CPU 权威合成结果生成透明 PNG，并以 `data:image/png;base64` 内嵌；不引用外部文件。矢量内容提供两种模式：

1. `保留矢量`：文字写为 SVG `text`；SVG 图元的 `defs`、分组与绘制节点展开到唯一根 `svg` 下，不输出嵌套 `svg` 或实现相关的命名空间前缀。
2. `栅格化矢量`：每个顶层组先按当前显隐、不透明度和顺序渲染，再嵌入 PNG。

组采用穿透式语义，导出时把有效不透明度应用到叶节点，避免引入 SVG 隔离组后改变现有显示结果。多个图元的渐变、遮罩或裁切资源使用导出时生成的中立短 ID，避免冲突；不得写入 Document、组、对象或子层 UUID。全透明栅格组不生成 `image` 占位；非空栅格使用 SVG 1.1 标准 `xlink:href` 内嵌一次 PNG，以兼顾系统缩略图、旧查看器和文件大小。输出不包含应用名称/版本元数据、图层树身份、选区轮廓、工具 Overlay、临时预览、脚本、动画和外部资源。

## 原子写入与验证

导出写入同目录随机临时文件，flush/fsync 后用禁用动画的 `QSvgRenderer` 重新打开、校验尺寸并完成一次实际渲染，最后通过 `os.replace` 原子替换。导出结构以 Qt SVG 可稳定处理的静态 SVG 1.1/Tiny 1.2 交集为目标，同时保持现代浏览器可读。失败或取消时删除临时文件并保持原目标逐字节不变。SVG 导出与其他图片导出一样不改变文档 revision、modified、撤销栈或恢复草稿。

所有外部图片格式都是中立交换格式：只写标准像素/矢量语义和显示所需的 sRGB ICC，不写 EasyPicture 名称、版本、内部 UUID、图层结构、撤销信息或项目路径。TIFF 的 Software 标签同样留空。EasyPicture 独有结构只允许存在于 `.limg`。

## 图层栅格化

矢量组和单个矢量子层均可在图层右键菜单中栅格化。结果使用与画布/导出相同的 Qt 矢量渲染适配层，写入固定画布大小的 `TilePixelStore`：

- 整组栅格化在原顶层位置替换为一个栅格组。
- 单个子层栅格化时按原堆叠位置拆分父矢量组，并在中间插入新的栅格组。
- 显隐和有效不透明度只应用一次，锁定对象拒绝转换。
- 一次转换对应一条撤销命令，撤销精确恢复组 UUID、子层顺序和矢量元数据。

## 后果

栅格化是破坏性类型转换，但可以通过撤销恢复；保存后重开只保留转换后的普通像素。P9B 不实现 SVG 动画、SMIL、脚本、滤镜编辑、CSS 完整级联、外部资源打包或浏览器级排版一致性。
