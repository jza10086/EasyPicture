# ADR-0032：精灵区域引用、整数坐标与 `.limg` schema v2

## 状态

Accepted for P10A，等待人工验收。

## 决策

精灵帧保存为画布内的半开整数矩形引用，不复制像素、不创建隐藏图层，也不改变源图。一个工程使用统一单格尺寸；帧名称、顺序、区域、锚点和网格尺寸属于工程内容并进入 revision、撤销和自动恢复。单格网格固定从画布 `(0, 0)` 开始；网格显隐、吸附和全局像素精确坐标仅保存到 QSettings。

帧缩略图与单帧 PNG 从当前 `DocumentSnapshot` 的 CPU 权威可见合成生成，包含栅格、文字和 SVG，不读取 GPU framebuffer，也不包含临时预览或 Overlay。源内容改变时区域定义保持不变，显示和导出随源内容更新。

`.limg` 升级到 schema v2，manifest 必须包含 `sprite_workspace`。正式 schema v1 迁移为空帧工作区；更早开发期格式不恢复。改变画布几何时，若存在帧必须先确认，成功提交时在同一几何命令中清空帧，撤销同时恢复画布与帧。

## 边界

P10A 不实现自动检测、批量切片、Atlas 重排、动画时间轴、洋葱皮、Tile 无缝检测、调色板、像素描边或碰撞轮廓。这些能力在 P10B～P10E 独立设计。
