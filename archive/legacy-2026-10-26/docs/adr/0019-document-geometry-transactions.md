# ADR-0019：文档几何事务与固定画布图层

- 状态：Accepted
- 日期：2026-07-28

## 背景

裁切、画布大小、图像缩放和图层尺寸操作会同时改变文档尺寸、图层尺寸与
origin、多个像素 Tile 以及选区。把这些变化拆成多个现有命令会暴露中间状态，
产生多个 revision 和撤销步骤，也无法在 PatchStore 超限时保证原子失败。

本应用优先轻量和可预测性，不再让每个图层拥有独立尺寸与无限画布外存储。所有图层
边界与文档画布一致，可以减少坐标、缓存、保存和几何操作的分支。

## 决策

领域层提供单一 `Document.apply_geometry_transaction()`，一次性应用：

- 文档尺寸；
- 任意图层的 size 与 origin；
- 任意图层的完整 Tile 差异；
- 选区 Tile 差异。

事务在修改任何状态前完成全部尺寸、origin、Tile 形状和边界校验。成功时只增加一次
Document revision；图层、选区和文档尺寸事件共享该 revision。命令层使用
`DocumentGeometryResult` 和一个复合撤销命令保存 before/after 几何与 PatchStore
句柄，预算确认或失败发生在执行前。

每个 `RasterLayer` 始终满足 `size == Document.size` 且 `origin == (0, 0)`。裁切、
调整画布大小和图像缩放会为每层生成新画布范围内的稀疏 Tile；画布外像素立即删除。
后续扩大画布只补透明像素，不恢复被裁掉的内容。复合撤销命令仍持有 before patch，
因此撤销原操作可以恢复全部旧像素。单图层缩放只缩放该层内容并放入固定画布，不改变
文档选区。

整文档几何操作即使遇到锁定图层也可以执行，因为它们改变的是文档坐标系；单图层几何
操作会拒绝锁定或透明像素锁定的图层。

## 边界规则

- 文档尺寸为 `1～8192`，所有图层尺寸与其相等；
- 图层 origin 固定为 `(0, 0)`；
- 裁切矩形允许负 origin，以便扩展透明画布；
- “裁切透明像素”使用所有图层 Alpha 非零像素的并集，不把隐藏 RGB 当作可见内容；
- 旧 `.limg v1` 中的独立 size/origin 在构造 Document 时裁切并归一化；
- 没有实际变化时不创建 revision、modified 或撤销命令。

## 后果

- 一次用户几何操作始终对应一个文档撤销步骤；
- 缩小画布会按产品约定删除画布外像素，只有撤销可以恢复；
- 大型缩放仍受 1 GiB PatchStore 预算与 JobRunner 取消和过期规则约束；
- `.limg v1` 无需变更，现有文档尺寸、图层 size/origin 和 Tile 条目已足够表达结果。
