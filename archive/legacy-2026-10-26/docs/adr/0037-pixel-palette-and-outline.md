# ADR-0037：像素调色与独立描边层

- 日期：2026-08-30
- 状态：已实施，等待 P10E 人工验收
- 关联：ADR-0023、ADR-0033、ADR-0036

## 决策

1. 提取、减色和描边只读取当前编辑文档的活动栅格层。源图与独立帧均可使用；引用帧、动画和 Tile 检查表面保持只读，不隐式独立化。
2. 颜色处理使用 display-referred sRGB straight RGBA。提取排除 Alpha=0 和选区权重=0 的像素；映射保留 Alpha，已存在 Tile 中的隐藏 RGB 继续参与映射。
3. 调色板允许 1～256 个不同 RGB。24-bit 颜色存在位表占 16 MiB；按固定 Tile 行列顺序及 Tile 内行顺序扫描，均匀抽取最多 262144 个有效像素，用 Pillow Median Cut 生成代表色。原色数不足目标时原样保留；空输入返回空调色板并提示。
4. 映射采用 D65 Lab/ΔE76，逐批、逐通道累加距离；相等距离采用调色板内靠前颜色。Floyd–Steinberg 跨 Tile 按整行扫描，透明像素不接收也不传递误差。工作面超过 64 MiB 使用既有临时 memmap。
5. 软选区仍按 mask/255 混合，可能产生表外颜色，UI 明确说明。色数是当前层有效区域的 RGB 统计，不是工程总色数或 Alpha 色数。
6. 本机命名预设及最后参数只写 QSettings；项目继续使用 schema v4，无调色板、描边效果或额外像素模型。
7. 描边使用阈值形状蒙版；4 邻域重复十字形态学、8 邻域重复方形形态学，分别得到曼哈顿/棋盘距离。外描边为膨胀减原形状，内描边为原形状减腐蚀；孔洞也参与。每 Tile 读取宽度大小的 halo，工作表始终小于 64 MiB。选区仅限制最后输出的 Alpha。
8. 描边作为同组内紧邻源层上方的新栅格层，100% 不透明度、正常混合，继承组属性；来源像素完全不变。创建、填充、选中新层为一个撤销命令，并沿用统一 100 条/1 GiB 预算。透明像素锁定不阻止生成；完全锁定源层/父组阻止生成。
9. 临时栅格层由协调器持有。软件与 OpenGL 使用同一 display_raster_children 顺序，将其插入真实堆叠位置；不使用顶层 Overlay。引擎结果 Tile 为只读，预览与提交使用现有 COW 接口交接，避免主线程重复复制整批像素。临时层既不进入 Document，也不进入 CPU 导出、缩略图或恢复。
10. 颜色映射、提取和描边共用 ColorAdjustmentController 的单运行任务/最新待处理请求、generation 与文档/活动层/revision 校验。旧完整预览保留至新完整结果到达；应用时冻结控件等待最新结果。取消、失败、表面切换及来源失效清理预览。

## 边界

不新增索引色文档、批处理、动画统一调色、持续跟随来源的描边效果或描边抗锯齿。画布外透明，输出裁切到画布；可能被截断时仅警告，不自动扩大画布或独立帧。

正式版本在人工验收后提升为 0.7.0；此前不创建版本提交或自动推送。
