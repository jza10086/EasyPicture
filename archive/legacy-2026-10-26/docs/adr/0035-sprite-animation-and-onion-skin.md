# ADR-0035：精灵动画、拍数时长与洋葱皮

状态：Implemented，等待 P10C 人工验收。

现有精灵帧分组升级为动画。一个帧最多属于一个动画；动画保存独立 FPS 和播放模式，帧保存 `duration_ticks`。实际时长由 `duration_ticks / fps` 唯一确定，不另存毫秒值。往返播放不重复首尾端点，单帧动画始终保持该帧。

动画画布是只读临时表面。linked 帧从根工程权威合成读取，detached 帧从嵌入文档权威合成读取；播放缓存只保存扁平 RGBA，不进入 Document、撤销或项目文件。调度以单调时钟和目标拍计算，QTimer 仅用于唤醒界面，避免累积间隔漂移。

动画洋葱皮沿实际播放路径选择前后帧，在统一单格坐标中比较邻帧与当前帧，只对发生像素变化的区域绘制着色残影；相同的不透明背景不会变成整幅滤镜。洋葱皮使用可配置颜色、基础透明度和距离衰减；锚点不参与动画像素对齐，只作为可调半径的红色视觉标记。精灵切片不使用着色洋葱皮，而显示保留原始 RGBA 的半透明参考帧，并绘制该参考帧的锚点；默认跟随最近创建帧，也可通过一次性拾取状态手动指定。两种预览和锚点标记均只属于显示状态，不进入缩略图、图片导出、Atlas、`.limg` 或撤销栈。

`.limg schema v4` 使用 `animations` 保存动画并为帧保存保持拍数；v3 分组迁移为 12 FPS、循环、每帧一拍的动画。Atlas JSON v2 保存动画顺序、FPS、播放模式和每帧保持拍数；PNG 布局仍按每个非空动画一行、未分组最后一行。
