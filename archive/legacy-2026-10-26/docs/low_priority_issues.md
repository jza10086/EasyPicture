# 低优先级问题清单

本文件记录已经确认、但暂不影响当前版本使用和验收的问题。低优先级问题不应通过牺牲数据正确性、撤销一致性或界面稳定性来快速掩盖；后续处理时应先补充可复现步骤和对比基准，再决定是否进入功能迭代。

## 状态定义

- **Open**：已确认，尚未处理。
- **Deferred**：已确认，但当前使用场景下暂不阻塞版本，等待专门的性能或渲染迭代。
- **Fixed**：已修复并完成针对性验收。

## 问题记录

### LP-001：图形预览与最终栅格化的边缘/分辨率差异

- **状态**：Deferred
- **来源**：P6C 图形工具验收
- **影响范围**：直线、矩形、圆角矩形、椭圆和多边形的临时预览与确认后像素结果。
- **现象**：拖动期间使用 QPainter 的矢量路径预览，确认或生成精确预览后使用 Pillow 超采样栅格化。两者在抗锯齿、像素取整、边界覆盖率和高缩放显示上存在轻微差异，因此预览看起来比最终结果更平滑或更“高分辨率”。
- **当前结论**：这是两套绘制路径的表现差异，不是画布尺寸变化、像素丢失或数据损坏。描边已经统一为中心描边；普通矩形使用直角连接，圆角矩形和椭圆保持各自几何语义。
- **当前规避**：最终结果以 CPU 权威栅格化结果为准；提交、撤销、保存和导出均不读取临时矢量 Overlay。相关图形测试和 standalone smoke 已通过。
- **后续方向**：
  1. 评估让临时预览复用同一套灰度覆盖率蒙版；
  2. 或在拖动结束后优先显示完整精确栅格预览，拖动过程中保留轻量矢量预览；
  3. 对 100%、200% 和更高缩放级别建立 QPainter/Pillow 像素对比基准。
- **暂不处理原因**：统一为单一渲染路径可能增加拖动延迟、后台任务压力和 Qt/无 Qt 边界复杂度；当前问题不影响最终像素正确性。

### LP-002：颜色调整预览更新不够实时

- **状态**：Deferred
- **来源**：P7A 颜色调整使用体验
- **影响范围**：亮度/对比度、伽马、曲线、HSL、渐变映射、颜色替换和调色板映射的连续参数拖动。
- **现象**：连续拖动参数时，预览帧率可能低于输入频率，偶尔出现短暂滞后。全分辨率调整需要遍历活动层 Tile；曲线、渐变映射和 Lab 调色板抖动的计算量更高，4096×4096 画布上更明显。
- **当前原因**：颜色调整采用 50 ms 防抖、串行 JobRunner、可取消任务和完整结果原子替换。新参数到达时会取消旧任务，但必须等待当前 Tile/扫描批次结束；新完整结果完成前继续显示上一份完整预览，以避免半成品、旧 Tile 混合和闪烁。
- **当前规避**：保持上一份完整预览；只接受最新 generation；应用、取消和文档替换均校验 document ID、layer ID 与 revision；最终结果和撤销命令不受影响。
- **后续方向**：
  1. 交互拖动期间使用低分辨率或可见区域预览，松开或应用时再计算全分辨率结果；
  2. 对 LUT/HSL 等可增量计算的调整复用中间结果；
  3. 评估并行 Tile 计算或 GPU 显示预览，但保持 CPU 结果作为提交权威；
  4. 为常用画布尺寸记录输入到完整帧的 P95 延迟和取消响应时间。
- **暂不处理原因**：当前架构优先保证预览原子性、可取消性和文档一致性；降低预览分辨率或引入并行后，需要额外验证选区、透明像素锁定、Alpha 0 隐藏 RGB 和颜色调整确定性。

### LP-003：P9E 路径节点与复合几何编辑

- **状态**：Deferred
- **来源**：P9D SVG 基础编辑范围收敛
- **影响范围**：任意 `path`、贝塞尔控制柄、路径拆分/连接/闭合、节点类型转换、布尔运算、复合路径和轮廓转路径。
- **当前结论**：P9D 只编辑可直接映射到标准几何属性的基础图元；复杂路径继续作为可显示、可变换、可导出的不透明 SVG 子层保留。
- **暂不处理原因**：路径编辑需要独立的节点选择、控制柄、曲线命中测试、拓扑撤销和标准化序列化系统，不能安全地塞入基础图元属性编辑。

### LP-004：P9F 高级 SVG 样式、排版与资源编辑

- **状态**：Deferred
- **来源**：P9D SVG 基础编辑范围收敛
- **影响范围**：渐变色标和方向、网格渐变、图案、蒙版、滤镜、剪裁路径可视化、完整 CSS 级联、复杂文字排版、文字沿路径、字体嵌入、任意深度组、动画、脚本及外部资源打包。
- **当前结论**：现阶段只解析安全的简单 CSS 和本地静态资源；受支持但不可编辑的资源尽量无损保留，不安全或无法解释的内容继续跳过并汇总警告。
- **暂不处理原因**：这些能力会引入浏览器级布局、资源依赖和复杂安全边界，不符合当前本机轻量编辑器的优先级。

### LP-005：存在矢量图层时画布拖动帧率偏低

- **状态**：Deferred
- **来源**：P9D 基础 SVG 支持人工验收
- **影响范围**：文档包含一个或多个可见文字或 SVG 矢量子层时的中键、Space 画布平移。
- **现象**：拖动画布时的帧率明显低于纯栅格文档；矢量对象数量、覆盖面积或内容复杂度增加后更明显。停止拖动后画面能够恢复为正确的完整帧，不影响权威像素、对象数据、撤销、保存或导出。
- **当前原因**：画布使用完整帧更新。矢量叶节点需要经过 Qt SVG/文字栅格化结果和 GPU/软件合成链路；平移期间连续请求新帧时，矢量缓存查找、纹理准备或重复栅格化可能占用较多主线程时间。
- **当前规避**：编辑复杂文档时可临时隐藏非必要矢量组，或降低同时可见的复杂 SVG 对象数量；最终显示与导出结果不受影响。
- **后续方向**：
  1. 分别记录纯栅格、文字、基础 SVG 和复杂 SVG 场景的平移帧时间；
  2. 检查平移是否错误触发矢量 Tile 重新栅格化或纹理上传；
  3. 为稳定矢量对象增加与缩放级别关联的复用缓存，平移只改变绘制矩阵；
  4. 在不恢复旧局部失效问题的前提下，评估视口外裁剪和缓存预热。
- **暂不处理原因**：当前问题属于交互性能，不影响画面最终正确性和工程数据；需要独立性能采样后再调整 P6R 的完整帧与缓存策略。

### LP-006：工程标签拖动排序动画不够自然

- **状态**：Deferred
- **来源**：P10B 多工程两级标签人工验收
- **现象**：拖动一级工程标签改变顺序时，标签位移和落点反馈不够连贯，视觉效果弱于常见浏览器或编辑器标签栏。
- **影响**：仅影响拖动过程的视觉反馈；最终工程顺序、活动工程、保存状态和标签内容正确。
- **后续方向**：评估自定义拖动占位、插入指示器及短时位移动画，并确保不会干扰 Qt 标签移动事件和工程会话索引同步。

### LP-007：精灵帧 Dock 重复显示工程标签

- **状态**：Deferred
- **来源**：P10B 多工程两级标签人工验收
- **现象**：主画布顶部与精灵帧 Dock 都显示工程一级标签，信息重复并占用 Dock 垂直空间。
- **影响**：不影响工程切换与帧分组，只增加界面冗余。
- **后续方向**：移除 Dock 内工程标签，使 Dock 始终跟随主画布当前工程；保留帧分组二级标签和工程切换后的状态恢复。

### LP-008：连续确认精灵切片存在短暂冷却

- **状态**：Deferred
- **来源**：P10A/P10B 精灵切片人工验收
- **现象**：在同一区域或相邻区域连续快速点击“确定”创建帧时，后续点击存在可感知延迟，缩略图与命令刷新越密集越明显。
- **影响**：创建结果正确且允许重复区域，不影响源图、撤销或导出；主要影响连续人工切片节奏。
- **后续方向**：分析命令提交、全量面板刷新和缩略图任务调度，将确认后的元数据提交与缩略图生成解耦，并合并同一事件循环内的非关键刷新。

## 后续登记规则

新增问题时至少记录：

1. 可复现步骤和画布/图层规模；
2. 期望结果、实际结果及是否影响权威像素；
3. 当前版本和渲染后端；
4. 临时规避方式、建议方向和验收标准；
5. 是否会影响撤销、保存、导出或恢复草稿。

低优先级问题进入实现前，应先确认它不会与当前已验收功能混淆；涉及数据正确性、文档损坏、崩溃或持续阻塞 UI 的问题，应升级为普通缺陷，不得继续留在本清单中。
