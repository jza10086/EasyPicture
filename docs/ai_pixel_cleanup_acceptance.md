# AI 像素整理：使用与验收

- 日期：2026-08-31
- 状态：Pending manual acceptance
- 属于 P10E 的新增流程；当前版本保持 0.6.0，和 P10E 一起验收后再决定发布/提交。
- `.limg schema v4` 不变；旧“调色板映射”仍保留原算法。

## 使用

选中栅格子层，打开 **颜色 → AI 像素整理…**。默认只减色（32 色），不会改变几何网格；自动生成配色后可锁色、编辑、从来源吸色或加载本机预设。第一次建议关闭抖动，以免 AI 杂色变成更多纹理点。

需要像素化时勾选“网格规范化”，手动调整像素块宽高和对齐 X/Y，查看橙色网格与逻辑分辨率。对齐只影响此处理网格，与工程的精灵单格设置无关。

- **色块优先**：选取格内主要色簇的代表原像素，较适合有杂色的 AI 像素风图；无法保证保留比网格更细的眼睛、轮廓等。
- **中心采样**：严格取格子中心，适合已经对齐的像素块；中心落在透明处则不自动补色。
- **保留原 Alpha**：只整理可见 RGB，保留原有透明边缘。
- **网格覆盖率 / 阈值硬边**：会改变透明轮廓。低分辨率新工程需要选择这两种重采样方式之一。
- **严格像素选区**：以 128 为界；有网格时处理整个格子，暗色覆盖提示未参与区域。
- **柔和混合**：保留软选区过渡，结果色数可能超过调色板色数。

颜色按钮单击选中、双击修改；修改和吸色自动锁定，锁色显示“锁”。锁色超过目标数时需要增加目标或解锁，不能应用旧结果。删除或排序色板进入“固定调色板”；点击“重新自动配色”可重新生成其余颜色，保留锁色。

抖动提供无、Bayer 2×2/4×4、Floyd–Steinberg。建议从低强度开始；开启网格时，抖动以逻辑像素为单位，不在一个像素块内部产生碎点。

默认输出为“新结果层并隐藏来源”，透明区域不会叠加两份半透明来源。撤销一次恢复原显示。选择“低分辨率新工程”则新开工程标签，不修改来源工程；请自行保存新工程。

关闭“显示结果”查看原图。Enter 应用、Esc 取消；数值框编辑内 Enter 仅结束输入，右键取消本次数值修改。空闲时右键“设为默认值”恢复默认参数。

## 人工验收（均 Pending）

1. AI 图片分别减到 8/16/32/64 色，对比原图与旧调色板映射；检查色数、细节与透明边缘。
2. 锁定眼睛/轮廓等关键色，编辑、吸色、预设保存与重启恢复；检查锁色超限阻断。
3. 连续拖动块宽高和对齐，测试色块优先/中心采样、非整除尺寸、网格关闭/开启。
4. 检查三种 Alpha 处理、严格/柔和选区和实际处理范围提示；了解轮廓变化与表外颜色。
5. 比较所有抖动模式与强度；放大检查抖动不打碎逻辑像素块。
6. 应用新结果层，确认来源字节不变、半透明无双重叠加、上方图层遮挡正确；连续撤销/重做。
7. 在独立帧内处理，检查来源不变；创建低分辨率新工程，检查尺寸、透明补齐及旧工程不变。
8. 快速改参、取消、切工程与图层、保存重开及单帧/Atlas 导出，确认无临时预览残留。

## 已知限制

不自动识别网格，不自动移除背景，不自动恢复丢失细节。透明棋盘格若已烘焙为图片像素也会被当作真实颜色。全图复杂噪声和误差扩散可能较慢，期间保留上一完整预览并可取消。更多操作说明见 [ADR-0038](adr/0038-ai-pixel-cleanup.md)。
