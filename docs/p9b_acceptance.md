# P9B 验收报告：静态 SVG 导入、导出与栅格化

## 状态

实现与定向自动验收完成，等待人工验收。

## 已交付

- 静态 SVG 导入；受支持的叶图元成为独立矢量子层，文字保持可编辑。
- 不支持或不安全内容跳过并汇总警告；外部资源、脚本和动画不进入文档。
- 软件/OpenGL 画布、缩略图、普通图片导出和 SVG 导出共用矢量渲染路径。
- SVG 导出支持保留矢量或栅格化矢量，并把栅格组作为内嵌 PNG 写入。
- 保留矢量导出使用单一根 SVG、无 `ns0` 前缀的扁平标准结构，并省略全透明栅格占位。
- SVG 和七种栅格格式不写应用身份、内部 UUID或图层结构；EasyPicture 独有信息只保存在 `.limg`。
- 支持标准嵌套 SVG 视口转换；SVG 子层选择不再触发文字对象查询异常。
- 矢量组/矢量子层右键栅格化，以及图层树全部展开/全部折叠。
- 当前 `.limg` schema v1、SVG 资源长度与校验和验证；开发期 schema v1～v4 不再兼容。
- `--svg-smoke-test <dir>` 源码与 standalone 专项冒烟入口。
