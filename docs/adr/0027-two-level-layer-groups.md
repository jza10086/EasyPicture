# ADR-0027：两级通用图层组与 schema v3

## 状态

Accepted for P9C.

## 决策

文档顶层只保存 `RasterGroupLayer` 或 `VectorGroupLayer`，组不能嵌套。栅格组只包含 `RasterLayer`，矢量组只包含 `VectorObject`；P9C 的矢量对象为 `TextObject`。节点按底到顶保存，图层树按顶到底显示。

组只穿透继承可见性、不透明度和锁定状态，不建立组级离屏表面或混合模式。`Document.layers` 继续提供扁平栅格兼容视图，`active_layer_id` 只允许指向栅格子层。

所有组与子层名称在文档范围内唯一；重名由命令服务追加 `.1`、`.2` 等后缀。删除组、跨组移动和取消分组通过一个可撤销命令完成，且最后一个栅格子层不能被删除。

## 持久化

`.limg` schema v3 使用 `nodes` 保存两级组结构。v1 先迁移到 v2，再把连续的栅格根节点合并为栅格组，把 `text_group` 转换为矢量组。未知组嵌套、类型不匹配、重复 UUID 或未来 schema 版本拒绝加载。Tile、选区和原子替换规则保持不变。

## 后果

软件渲染、OpenGL、CPU 合成、缩略图和导出均遍历相同的有效叶节点；组排序或属性变化只刷新显示，不改变权威像素。未来加入 SVG 只需扩展矢量子层联合类型，不改变树结构。
