# ADR-0025：图层树、文字组与文字对象生命周期

## 状态

已接受（P9A）。

## 决策

文档以 `nodes` 作为顶层、底到顶的权威顺序。栅格层仍通过 `Document.layers`
提供兼容视图；文字对象只能位于一个文字组内，P9A 不允许任意深度嵌套。
组和对象的可见性、不透明度及锁定属于文档状态；树的选择与展开状态属于 UI，
不改变 revision 或 modified。

所有创建、删除、排序和属性修改都经过 `DocumentCommandService`，在确认时形成
一个 QUndoStack 命令。文字对象保留 UTF-8 文本、固定文本框和二维仿射变换，
不会因栅格工具选择而自动栅格化；栅格工具只接受 RasterLayer。

## 取舍

保留平面栅格 API 可让现有画笔、选区、调整和导出代码渐进迁移，同时树模型只需
处理两级结构。跨组拖放、富文本、沿路径文字和任意深度组层留待后续阶段。
