# ADR-0016：四边形变换、交互状态与变换预览

- 状态：Accepted
- 日期：2026-07-27

## 决策

自由变换使用 Qt 无关的 `ProjectiveTransform` 作为统一几何表示；规则矩形也由同一
3×3 矩阵表达。工具会话捕获
document ID、layer ID、revision、源边界、源中心点和不可变 `DocumentSnapshot`。
移动、单边缩放、规则角点缩放、旋转和不规则四角编辑都只更新会话矩阵，不修改
Document。关闭“不规则编辑”时四角保持规则矩形，开启时允许独立移动角点，但拒绝
自交、退化或超过项目边界的四边形。

自由变换不写入普通文档 `_composite_cache`。会话开始后，渲染器分别缓存活动层以下
（存在选区时包含活动层原位剩余部分）和活动层以上的静态合成；活动内容继续引用按
Tile revision 缓存的源 QImage，并在 `CanvasItem.paint()` 的同一次绘制中按以下顺序
显示：

1. 下方静态合成；
2. 使用当前矩阵直接绘制的活动内容或浮动选区；
3. 上方静态合成。

每次鼠标更新只发布新的不可变 `TransformPreviewFrame`，其中包含 layer ID、矩阵、
插值方式和单调递增 generation。16 ms 定时器合并高频更新，画布一次绘制只读取一个
generation，不允许按目标 Tile 渐进生成不同矩阵帧。取消后普通权威合成缓存仍然
有效，提交后只由正式文档事件执行一次普通失效。

预览矩阵变化不计算目标 Tile 脏区。旋转或投影可能跨越画布边缘，基于裁切后包围盒的
局部失效会遗漏“出界后重新进入”的区域；因此每个合并帧请求整个可见 viewport
重绘，`QGraphicsView` 仍负责裁切到实际屏幕范围。该规则避免旧局部 exposed rect
继续限制源 Tile 可见性计算。

缩放低于 50% 时，活动内容建立会话级 LOD 图集，长边限制为 2048 px；同一会话的
矩阵变化复用该图集。高缩放继续直接绘制可见源 Tile。LOD、上下层静态缓存和普通
合成共同遵守 256 MiB 渲染预算，变换期间优先淘汰暂不显示的普通合成结果。

变换框使用八个屏幕尺寸固定的边/角手柄、四个角外侧曲线旋转手柄、中心点和纯橙色
轮廓。右侧属性面板提供四角精确坐标，顶部保留中心、尺寸和旋转数值。参数回写不得
写入正在交互的数值控件。普通选区轮廓在会话期间隐藏。Enter 或应用按钮提交，
Esc、工具/文档/图层切换、正在变换的图层被删除或 revision 失配时安全取消。

## 后果

- 拖动不会反复重采样权威像素；
- 拖动不会生成或缓存“矩阵 × 目标 Tile”的派生结果；
- 变换框与像素来自同一个 preview generation，不再混合旧姿态；
- 画布缩放、平移和预览不会改变 modified 或 revision；
- 浮动状态仅属于运行时，不进入 `.limg`；
- 当前投影能力只服务于四角不规则编辑；网格变形仍不在本 ADR 范围内。
