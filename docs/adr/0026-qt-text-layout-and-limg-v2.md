# ADR-0026：Qt 文本布局统一渲染与 `.limg` schema v2

## 状态

已接受（P9A）；其中 schema v2 与迁移部分已被 ADR-0030 取代。

## 决策

领域层不持有 Qt 类型。文字预览、CPU 合成、缩略图及七种图片导出共用
`QTextLayout/QPainter` 适配层；字体只保存名称，缺失字体使用本机确定的回退字体，
并提示一次。文本固定在文本框内自动换行、裁切，颜色和组/对象不透明度按
straight RGBA 语义绘制。

项目格式升级到 schema v2。顶层使用 `nodes` 保存栅格节点与文字组，文字组的
`children` 保存文字对象元数据；栅格 Tile、选区 Tile 和原子 ZIP 写入规则保持不变。
读取 v1 时由迁移器把 `layers` 包装为 raster nodes；保存统一写入 v2，同时保留
`layers` 只读镜像供旧诊断工具使用。渲染缓存、撤销历史和临时编辑状态不入项目。

## 取舍

OpenGL 后端继续使用预乘纹理；文字先由 QPainter 派生，必要时在完整帧后叠加，
避免把字体光栅化缓存反向写入权威像素。嵌入字体、富文本和 SVG 进入 P9B 或更后阶段。
