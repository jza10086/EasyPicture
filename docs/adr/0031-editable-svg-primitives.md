# ADR-0031：可编辑基础 SVG 图元与标准 XML 持久化

## 状态

Accepted for P9D.

## 决策

基础 SVG 图元的权威数据继续是 `SvgElementObject.svg` 中的标准 SVG XML。运行时可把单个矩形、圆、椭圆、直线、折线或多边形解析为 Qt 无关的冻结几何与样式值对象；修改后只重写对应标准属性，并保留安全的 `defs` 和本地资源。`.limg schema v1` 不保存重复几何字段，也不为 EasyPicture 增加 SVG 私有命名空间。

图形工具提供栅格和矢量输出。矢量输出创建标准基础图元，临时会话通过渲染协调器原子替换当前矢量组预览；确认后只形成一个对象命令。已导入的可编辑图元使用同一解析、预览和提交路径。折线与多边形的顶点坐标在属性栏中以文档坐标显示，写回时通过对象逆变换转换为 SVG 局部坐标。

填充和描边支持无、纯色及只读本地资源引用；基础样式包括宽度、端点、连接、斜接、虚线和填充规则。导入可解释表现属性、内联样式，以及元素、类、ID和 `tag.class` 简单选择器；复杂选择器跳过并警告。复杂 SVG 文字只有在能够无损映射时才转换为 `TextObject`，否则作为 SVG 图元保留。

## 交换格式边界

SVG 导出只写标准静态 SVG。可编辑基础图元保持其标准元素类型；栅格组或选择栅格化的矢量组以 `data:image/png;base64` 内嵌。导出不包含文档 UUID、图层树、展开状态、撤销信息、编辑会话或应用元数据。现代 `href` 是内嵌图片的默认引用形式，资源 ID 在导出时确定性重写。

## 延期

任意路径节点、贝塞尔控制柄、布尔运算、渐变可视化编辑、蒙版/滤镜、完整 CSS、富文本和任意深度 SVG 组进入 P9E/P9F 候选，并记录在低优先级问题清单。它们不阻塞 P9D。
