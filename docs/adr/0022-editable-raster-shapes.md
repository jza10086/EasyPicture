# ADR-0022：临时可编辑栅格图形

- 状态：Accepted
- 日期：2026-07-28

## 背景

EasyPicture 需要直线、矩形、圆角矩形、椭圆和多边形，但项目仍以栅格图层为唯一
可编辑内容。若鼠标释放立即写入文档，用户无法继续调整几何；若把几何写入项目，则会
引入矢量图层、文件格式迁移和另一套撤销模型。

## 决策

1. 图形在确认前由 `ShapeEditSession` 持有，不进入 `Document`、`.limg` 或自动恢复。
2. 拖动期间只更新固定屏幕尺寸的橙色矢量 Overlay；离散操作结束后才按 Tile 生成
   精确私有像素预览。
3. 私有预览通过统一画布协调器放在活动层位置绘制，因此仍受上方图层遮挡；刷新新预览
   前必须清除旧 Tile，不能把不同几何的私有 Tile 合并。
4. 普通预览同步生成；影响超过 400 万像素或 64 Tile 时交给 `JobRunner`。后台结果必须
   同时匹配 session generation、document ID、document revision 和 layer ID。
5. 填充先于描边。描边色和填充色独立持久化，并共享不透明度、抗锯齿、选区权重和
   `PaintBlendMode`。
6. 栅格化在带 padding 的灰度蒙版上进行；抗锯齿使用 4 倍超采样，避免 Tile 边界独立
   缩小造成接缝。
7. 会话中的创建、移动、缩放、顶点和属性修改进入轻量几何历史；文档确认只调用一次
   `apply_pixel_tiles()`，形成一个“绘制图形”撤销命令。
8. 工具、图层、文档或 revision 变化必须清除 Overlay、私有预览和后台任务。
9. 图形裁切到画布，画布外部分不保存；P6C 不引入矢量图层或项目格式字段。

## 结果

- 用户可以在写入栅格层前反复调整几何并撤销会话步骤；
- 保存、恢复、导出和现有撤销格式不需要迁移；
- 精确预览与最终提交复用同一 Qt 无关栅格化服务；
- 大图预览具备取消和过期结果隔离，但常用图形不承担后台调度开销。
