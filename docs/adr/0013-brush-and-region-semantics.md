# ADR-0013：画笔、橡皮与区域识别语义

- 状态：Accepted
- 日期：2026-07-24

## 决策

P4 画笔采用圆形 dab、跨指针事件保留余量的固定间距插值和 straight RGBA
source-over。大小的默认拖动范围为 1～1024 px，手动输入范围为 1～8192 px；
拖动超过默认范围时钳制，手动超出默认范围后比例填充保持为满格。硬度、不透明度为
0～1；间距为直径的 0.01～2.0，这些比例参数不允许手动越界。抗锯齿在外缘提供
一像素覆盖过渡。P4 只接收鼠标输入，不解释压力、倾斜或笔速。

橡皮与画笔共享 dab 和插值，只按覆盖率降低 Alpha，始终保留原 RGB，包括 Alpha
降为 0 后的隐藏颜色。选区没有已分配蒙版 Tile 时表示无约束；否则所有像素工具将
蒙版权重乘入覆盖率。

油漆桶和后续魔棒复用 `RegionQuery`/`RegionResult`。容差定义为 straight RGBA 四个
通道最大绝对差，范围 0～255；连续模式支持 4/8 邻域，非连续模式选择全部匹配像素。
默认对当前层、连续、4 邻域、容差 0 取样。合并取样只改变区域判定，写入目标始终是
活动层。

油漆桶另提供 0～8 px 的边缘覆盖，默认 1 px。扩展采用不穿越完全不透明像素的
受限膨胀；新增的边缘像素将填充色合成到现有半透明像素后方，而不是覆盖其前景色。
这样可以填实画笔抗锯齿边缘，同时保留原有轮廓并避免跨过不透明边界。

## 原因

固定 RGBA 距离能明确区分透明度不同但 RGB 相同的像素；保留隐藏 RGB 与项目格式的
无损像素契约一致。共享区域服务可避免 P5 魔棒复制填充算法。

## 后果

- 画笔、橡皮和填充都遵循相同的选区权重和锁定规则；
- 显示缓存不作为吸管或油漆桶的权威取样来源；
- 更感知一致的 Lab 距离、自定义笔尖和数位笔输入需要独立后续阶段。
