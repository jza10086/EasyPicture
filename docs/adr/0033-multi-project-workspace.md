# ADR-0033：多工程工作区与两级编辑表面

状态：Accepted（P10B 人工验收通过）

EasyPicture 在一个主窗口内由 `WorkspaceController` 管理多个 `ProjectSession`。每个工程保留独立的 `ApplicationController`、文档生命周期和 `QUndoStack`，公共 UI 通过稳定命令代理及 `QUndoGroup` 绑定当前工程，不因切换标签清空历史。

主画布一级标签代表工程，二级标签代表源图或已打开的引用/独立帧。源图视图不可关闭；引用帧以当前源区域的权威合成提供只读视图，独立帧绑定嵌入文档；关闭帧标签只关闭编辑表面，不删除帧。画布表面切换会取消旧的临时预览，并把命令目标切换为源文档或嵌入帧文档。保存始终提交父工程。

普通工程不会在重启时自动打开。恢复草稿以工程 UUID 命名并独立清理。工作区标签、活动表面、缩放和折叠等仍为 UI 状态，不进入 `.limg`。
