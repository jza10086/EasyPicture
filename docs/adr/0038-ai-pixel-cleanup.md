# ADR-0038：AI 像素风素材的网格规范化与感知减色

- 日期：2026-08-31
- 状态：Implemented；人工验收待完成
- 关联：ADR-0037（普通调色板映射与像素描边）、ADR-0032/0033（帧与嵌入文档）

## 决策

增加独立的“颜色 → AI 像素整理…”流程，不替换 P10E 的 Median Cut 提取与 D65 Lab 映射。不调用生成式模型，不自动识别 AI 图片中的真实像素网格，也不承诺恢复丢失的细节。

1. 输入是活动栅格层的不可变快照，不是可见合成或 GPU 缓冲；源图和独立帧可用，引用帧需用户先独立化。
2. 统计 Alpha>0 且选区权重>0 的 RGB。用 24 位位图统计精确色数、6 位/通道加权直方图做聚类；权重为 Alpha×选区，细节保护只增加至多 35% 的局部边缘权重。边缘检测读取 Tile halo。
3. 原色数及锁色并集不超过目标时保留精确原色。否则在 OKLab 中进行确定性加权中位切分初始化和最多 8 次 K-means；锁色是固定中心，空簇由最大加权误差重新播种。调色板去重，数量可少于目标。
4. OKLab 使用标准 sRGB 解码/矩阵；聚类色超出 sRGB 色域时保留亮度、色相并缩小色度，最后量化到字节。此转换仅服务颜色距离，不改变工程的 straight RGBA/sRGB 像素契约。[OKLab 原始定义](https://bottosson.github.io/posts/oklab/)
5. 网格完全由用户指定整数宽高和相位，原点为 `(-offset_x, -offset_y)`，偏移范围为 0～对应块尺寸−1。逻辑尺寸使用向上取整；画布外透明补齐。色块优先按调色板簇累计 Alpha/选区权重，从获胜簇选择距其均值最近的原像素，平局按距格心距离与 RGB 决定。中心采样不寻找替代像素。
6. 网格覆盖率将原始 Alpha 总和除以完整格面积；中心采样保留中心样本 Alpha。保留 Alpha 模式保持原画布透明轮廓和 Alpha=0 的隐藏 RGB；硬边模式应用指定阈值。透明度重采样可能改变轮廓，必须明确提示。
7. 严格选区按覆盖率≥128 整格处理，其余保持来源；柔和模式按覆盖率混合，允许产生表外颜色。低分辨率新工程的未选中格透明，不复制原图非选中内容。
8. 抖动在逻辑像素网格上计算：无、Bayer 2×2/4×4、蛇形 Floyd–Steinberg；强度 0 等同无抖动。仅映射可见且参与处理的像素，误差不写入或由完全透明/未处理像素传播；邻行误差乘 Alpha 和强度。
9. 默认完整同尺寸结果层替代来源显示，保留来源层的不透明度/显隐及父组堆叠，应用后隐藏来源；一条命令恢复新层、来源显隐和活动层。源像素不变，无变化不创建命令。
10. 低分辨率输出创建新的未保存工程，不改变来源工程的 revision、撤销、尺寸或帧数据。不能在单个低分辨率像素中保留原分辨率逐像素 Alpha，因此此输出只提供重采样 Alpha。

## 生命周期与资源

复用颜色调整会话：一个运行任务和最新待处理请求，参数冻结后等待最新结果，来源/编辑表面/revision 变化取消。完整预览在协调器内一次替换；不进入保存、缩略图、帧/Atlas 或图片导出。采样与分析缓存只属于本次会话，不跨文档复用。

超过 64 MiB 的 RGBA 工作表复用临时 memmap，结束立即关闭映射后删除目录。颜色距离分批计算；大网格分两遍有界取样，避免整格×颜色数矩阵；误差扩散只保留两行误差。按 Tile、行与聚类迭代检查取消。

本机 QSettings 只记参数与命名 RGB 预设；当前锁色、临时调色板、采样框和处理历史不写入项目。`.limg schema v4` 不变。

## 边界

不增加背景自动移除、网格自动检测、对象识别、逐帧自动统一色板或局部笔刷约束。锁色确保调色板包含指定颜色，不保证细小结构经过粗网格后仍存在。继续保留用户手工修整和旧调色板映射入口。
