# ADR-0020：裁切、缩放与完整帧几何预览

- 状态：Accepted
- 日期：2026-07-28

## 背景

P6R 已确立完整帧渲染和单一 `CanvasRenderCoordinator`。P6B 的裁切与尺寸对话框若再
建立独立的最终合成缓存或 dirty rect 链，会重新引入旧帧、截断和预览残留风险。

## 决策

所有几何预览继续通过 `CanvasRenderCoordinator`：

- 每次参数变化替换一个不可变 `GeometryPreviewState` 并增加 frame generation；
- 画布大小预览使用新画布尺寸和锚点平移矩阵；
- 图像缩放预览使用全局缩放矩阵；
- 图层缩放预览只变换活动层；
- 预览期间隐藏权威选区轮廓，退出后恢复；
- 取消、文档替换、任务完成或失败均清理预览并恢复实际 CanvasBounds。

几何对话框活动期间，统一帧使用 QPainter 软件参考路径直接绘制当前源 Tile，不创建
最终合成缓存。提交后立即恢复所选 OpenGL 或软件后端。这样会牺牲大型文档的瞬时预览
性能，但确保预览、取消和最终提交不会混用旧 framebuffer；当前产品优先面向通常不
超过 4096×4096 的本机编辑场景。

裁切工具不重采样像素。它使用独立 Overlay 展示：

- 可越过原画布的裁切框；
- 原画布外的透明棋盘格；
- 框外遮罩、纯橙色边界、八个手柄和可选三分网格；
- 自由、原始、常用比例和自定义比例；
- 数值坐标、Enter 应用、Esc 取消及右键恢复当前拖动。

## 后台与提交

实际计算由串行 JobRunner 接收不可变 `DocumentSnapshot`、参数和取消令牌。主线程
只负责预览和将 `DocumentGeometryResult` 提交到命令服务。超过 150 ms 才显示进度
对话框；返回时由 document ID 与 revision 校验过期结果。

## 后果

- 对话框拖动数值时始终展示最新 generation；
- 取消不会留下预览姿态、CanvasBounds 或选区可见性残留；
- OpenGL 几何预览暂时不是原生 shader 路径，但普通编辑与提交后显示仍使用 GPU；
- 后续若实测软件几何预览不足，可把相同状态映射到 OpenGL uniform，而不改变工具、
  命令或领域接口。
