# ADR-0025：本机日志、临时文件与用户提示

- 状态：Accepted
- 日期：2026-07-30

## 背景

EasyPicture 0.1.0 仅用于当前 Windows 计算机和单用户离线场景。P8 的重点是让日常故障
可以定位、遗留工作文件可以安全清理、常见文件可以快速重开，而不是建立跨平台发布体系。

## 决策

### 日志

- 使用 Python 标准库 `logging` 和 `RotatingFileHandler`，不增加依赖。
- 日志位于 `QStandardPaths.AppLocalDataLocation/logs/easypicture.log`。
- 单文件上限 2 MiB，保留 5 个备份，统一使用 UTF-8。
- 记录软件和依赖版本、任务状态、文件生命周期、渲染后端、清理摘要及未捕获异常。
- 可以记录用户主动操作的文件路径，但禁止记录图像像素、Tile 字节或项目正文。

### 临时文件

- memmap 和算法工作目录位于 `QStandardPaths.CacheLocation/temp`。
- 根目录和任务目录均带有 EasyPicture 所有权标记。
- 启动时只清理该根目录中超过 24 小时的已标记任务目录和 EasyPicture 命名文件。
- 正常退出尝试清理本次会话仍登记的工作文件。
- 原子保存/导出的同目录临时文件，只在写入同一目标前清理与该目标精确匹配且超过
  24 小时的兄弟文件。
- 恢复草稿及 `.corrupt` 隔离文件不是临时缓存，绝不自动删除。

### 提示

- 正常成功和取消使用状态栏。
- 可恢复问题使用非模态通知，并按稳定 key 在短时间内去重。
- 需要用户决策或无法安全继续的操作继续使用模态对话框。
- 错误对话框提供日志目录入口；详细 traceback 只写入日志。

### 最近文件

- 使用 QSettings 保存最多 10 个绝对路径，按 MRU 排序。
- Windows 路径去重不区分大小写。
- 成功打开普通图片、打开 `.limg` 或保存 `.limg` 后加入。
- 不存在的路径在用户尝试打开时立即移除，并且不替换当前文档。
- 路径存在但内容损坏时保留记录，因为用户可能在外部修复文件。

### 版本

- `src/easypicture/version.py` 是版本号唯一来源。
- `pyproject.toml` 通过 setuptools dynamic version 读取该值。
- P8 内部稳定版版本号固定为 `0.1.0`。

## 后果

本机问题具有可复制的诊断信息，崩溃遗留工作文件不会无限积累，最近文件失效也不会破坏
当前编辑状态。作为取舍，P8 不验证其他操作系统、其他计算机、安装器或长期压力场景。
