# ADR-0005：`.limg`、sRGB 与保存/导出边界

- 状态：Accepted
- 日期：2026-07-23

## 决策

V1 使用 8 位 sRGB 作为唯一工作空间。带受支持 ICC 的导入图片转换到 sRGB；
无 ICC 图片按 sRGB 解释。V1 不提供 CMYK、HDR 或多工作色彩空间。

`.limg` 是唯一保留图层和项目状态的可编辑格式。保存/另存为写入 `.limg`；
PNG、JPEG、WebP、BMP、TIFF 和 TGA 通过导出生成。导出成功不能清除项目 modified
状态，只有 `.limg` 保存成功后才能标记撤销栈 clean。

## 原因

把原 ICC 直接附回已经在另一颜色空间编辑过的像素会产生错误颜色。区分保存和导出
可以避免用户误以为普通图片保留了图层。

## 后果

- `.limg` 需要版本化 schema、迁移入口、输入校验和原子保存；
- JPEG 导出必须先处理透明背景；
- P0 只冻结格式边界，不实现项目读写。
