# P3 项目持久化基准

- 日期：2026-07-23
- Python：3.14.3 x64
- 系统：Windows 10 10.0.19045
- CPU：AMD64 Family 25 Model 80
- 物理内存：约 63.42 GiB

## 场景

实际创建 4096×4096、10 个全尺寸密集图层，共 2560 个 256×256 Tile 和
640 MiB straight RGBA 权威像素。图层使用不同的固定半透明颜色；保存包含
`.limg` 写入、flush/fsync、完整重读校验和缩略图生成。

## 结果

| 指标 | 结果 | 门槛 | 状态 |
| --- | ---: | ---: | --- |
| 文档快照 | 1.543 ms | < 100 ms | PASS |
| 保存并完整复核 | 8700.060 ms | 记录 | PASS |
| 项目重开 | 907.899 ms | 记录 | PASS |
| 取消响应 | 16.682 ms | < 1000 ms | PASS |
| 项目文件大小 | 7.52 MiB | 记录 | PASS |
| 保存 RSS 峰值 | 827.09 MiB | 记录 | PASS |
| 加载 RSS 峰值 | 1.32 GiB | 记录 | PASS |

加载峰值包含原 640 MiB 文档和新加载文档同时存在。这是“加载失败不得破坏当前
文档”的代价；打开前的格式和解码总量限制用于阻止不受控分配。

完整机器可读结果位于被忽略的 `build/benchmarks/p3.json`。复现命令：

```powershell
.\scripts\benchmark-p3.ps1
```
