# P9A 验收报告：可编辑文字矢量图层与通用子图层

## 状态

实施完成，人工验收通过。P9C 将文字组升级为通用矢量组，旧 v2 项目继续由迁移器读取。

## 已交付

- `Document.nodes`、`VectorGroupLayer`、`TextObject` 及同步领域事件。
- 文字组/文字对象创建、删除、复制、排序、属性修改和 QUndoStack 命令。
- `.limg` schema v2 写入，v1 读取迁移，Unicode 文本和文字对象字段校验。
- QTextLayout/QPainter 文字适配层，接入软件画布、CPU 合成、缩略图和图片导出。
- 含文字组时的 QTreeView 图层树；旧栅格列表 API 保持兼容。
- 文字工具拖动并松开即创建固定文本框；创建期间右键取消。
- 文字框边线使用固定屏幕线宽，缩小画布后仍保持可见；临时文字不再重复覆盖真实矢量预览。
- 文字属性页支持实时修改内容、字体、字号、颜色、描边颜色及描边宽度，无需“应用”；内部滚动允许右侧属性区继续缩小。
- 文字属性页支持“自动换行/手动换行”：自动模式逐字符截断换行，手动模式只响应显式换行符并裁切横向溢出。
- 文字组和文字对象均提供 48×48 图层树预览，属性变化后同步刷新。
- 选中文字对象即显示规则八点变换框；边中点单轴缩放、角点双轴缩放。
- 文字移动、缩放、旋转和中心点拖动实时同步右侧属性；松开后合并为单条撤销命令。
- 旋转围绕可编辑中心点执行，属性页提供中心 X/Y；四角外延旋转标沿用自由变换曲线箭头。
- 未选中文字组时创建文字会自动新建文字组；选择文字组时直接在组内创建子对象。
- 选择子文字对象时，新对象创建在同组并位于所选对象正下方；未选中的文字对象不响应画布命中或拖动。
- 顶层节点及同组文字对象名称保持唯一，重名自动追加 `.1`、`.2` 后缀。
- 图层树提供外边框、行分隔和层级辅助线；文字属性与矩形自由变换参数在同一属性页分区显示。
- 右侧文字属性面板及文字对象选中时栅格工具禁用。
- 文字对象可通过文字工具双击编辑，并可通过自由变换入口移动、缩放和旋转；确认后只提交对象命令。
- 图层树支持顶层及同组内拖放排序，组展开状态通过 QSettings 记忆。
