# 栅格对象与独立像素标签页

## 使用方式

主画布用于编排对象和创建矢量。使用“添加栅格对象”拖出矩形，创建透明的局部像素区域；
宽高为矩形向上取整的像素数，范围为 1～8192。创建后继续保持该工具。
蓝色虚线表示栅格对象范围，随对象变换预览移动，只用于编辑显示，不进入导出图片。

选中栅格对象，点击工具栏或右键菜单的“编辑栅格像素”，在主窗口内打开
“栅格：对象名称”标签页。每个工程／独立帧中的同一对象仅打开一个标签页。
该页按对象原始像素尺寸编辑，提供画笔、橡皮、油漆桶、魔棒、矩形选区和吸管。
“返回对象画布”回到源画布或所属独立帧，栅格页仍可再次选择；关闭栅格页也会返回所属画布。

像素页独立显示对象内容，不套用对象矩阵、对象透明度和祖先透明度。
它的选区与主画布选区分开，取样和填充仅使用该对象的局部内容。
像素修改立即写回原对象，保留原位置、旋转、缩放和对象属性。
保存始终保存所属工程；撤销、重做共用该工程历史，不需要额外应用或复制回主画布。
祖先锁定会禁止进入编辑，切换页面取消未完成笔划，删除目标会关闭对应标签。

主画布中的栅格变换采用对象操作。像素页不开放对象结构修改、矢量创建和追加工程入口。
文字与 SVG 的内容编辑仍通过“矢量内容编辑”模式进入；选中已有 SVG 后选择图形创建工具
会继续创建新对象，而不会隐式编辑已有图形。

## 新建对象的集合规则

- 选中集合：插入该集合。
- 选中任意对象：插入该对象的父集合；根对象的新兄弟仍在根层。
- 无有效选择：插入根层。
- 锁定的父集合：拒绝创建。

文字、图形、栅格矩形共用 `tools/insertion.py`，不自动创建专用栅格组或矢量组。
新对象成为活动对象，连续创建保持当前工具，一次创建对应一条撤销。

## 实现边界

`RasterEditDocument` 是工作区内的局部编辑投影，拥有独立视图 ID 和局部选区，
Tile 使用可写时复制，像素命令转发到所属权威文档的对象 ID。
投影不参与序列化，schema v5 不变。关闭标签后保留命令引用所需的投影，
关闭工程释放订阅；撤销对象删除后，之前的像素撤销仍可作用于恢复的对象。

页面状态使用 `EditingSurfaceRef(kind="raster", frame_id, object_id)` 定位，
独立帧写入其嵌入文档，源画布像素不受影响。
元数据同步不发送像素失效事件；对象边框使用渲染协调器的当前变换预览。

## 人工验收

自动验证使用离屏 Qt 事件与虚拟指针，不执行 Windows 原生鼠标操作，不做文件或资源哈希校验。
以下项目仍由用户验收：

- 连续添加多个栅格区域，选中 SVG 后创建矩形／文字／栅格区域，检查它们保留同一父集合。
- 在栅格页长时间绘画、橡皮擦除、填色、选区与取色，检查鼠标捕获、窗口边缘、光标恢复。
- 主画布旋转、缩放栅格，再进入像素页绘画并返回；检查对象位置和显示效果。
- 反复切换源画布、栅格页、独立帧和工程，检查撤销、标签关闭和未完成笔划取消。
- Esc／右键取消新建区域、窗口切换、保存后重新打开，检查没有误创建或遗漏像素。

硬件 OpenGL 和原生鼠标手感不由离屏软件渲染结果代替。
