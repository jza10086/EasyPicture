# 矢量与位图编辑界面

## 布局

参考 Affinity Designer 的 Persona 与 Context Toolbar 分工，主窗口左上设置
“矢量编辑”和“位图编辑”两个入口。矢量界面处理对象、集合、文字和图形；
选中栅格对象进入位图界面后，使用对象专属标签页编辑局部像素，工具栏只显示像素工具。
两种界面共用工程历史与保存，不生成副本，也不改变 schema v5。

- 左侧：当前工作区的图标工具栏，悬停显示工具名和快捷键。
- 顶部：当前工具的设置；“详细设置”展开角点、图形几何、切片及处理任务等复杂参数。
- 右上：矢量界面的对象大纲，按对象类型显示图标。位图界面隐藏对象大纲。
- 右下：对象属性，包含不透明度、锁定、对象变换、文字或 SVG 内容属性。
  “颜色”标签整合原主颜色／副颜色面板；位图界面默认显示该标签。

选择对象更新右侧属性，切换工具更新顶部参数，二者互不抢占。
旧的浮动面板布局版本失效，重新使用本次布局；工程内容不迁移。

## 导航与选择

滚轮直接以指针位置为中心缩放；中键或 Space 拖动继续用于平移。
小幅滚动按增量比例缩放，零纵向滚动不改变视图。

对象选择工具顶部提供“忽略透明像素”，偏好持久保存，默认关闭。

- 关闭：按对象范围选取，透明或新建的空栅格区域也能选中。
- 开启：点选跳过有效不透明度为零的对象，以及点击处透明的像素／SVG／文字内容。
  栅格通过逆变换读取局部像素 Alpha，SVG 和文字仅渲染命中点的单像素覆盖率。
- 任意非零 Alpha 都可命中。框选也遵循该开关：框内必须与可见内容相交，
  仅覆盖空白、空心图形内部或透明像素不会选中。栅格按变换后的像素单元判断；
  SVG／文字以原分辨率分块检查覆盖，避免缩小采样漏掉细线。
- 显隐、集合继承、锁定和多选规则保持原有语义；选择偏好不进入撤销历史。

## 对象快捷键与创建

在矢量画布或大纲内使用 G 移动、S 缩放、R 旋转，移动指针预览，左键或 Enter 确认，
Esc／右键取消。G／S 支持 X、Y 轴约束，再按同一轴解除；Shift 精调。
缩放、旋转默认使用当前选中对象的共同中心，也可在右下属性中指定共同中心。
每次确认只产生一条撤销；取消、窗口失活及无变化操作不产生历史。
Del 删除选中对象，锁定目标使整个操作拒绝。文本编辑中的字母及 Delete 仍交给文本框，
位图编辑中的 G 仍为油漆桶，Del 仍为清除选区像素。

左侧“创建对象”统一提供“矢量对象”和“位图对象”二级菜单；Shift+A 打开同一菜单。
矢量菜单包含直线、矩形、椭圆、三角形、折线、多边形和文字。选定类型后在画布创建，
仍沿用当前对象的父集合。创建成功后选中新对象并切回对象选择工具，下次使用 Shift+A 重新选择类型。普通矩形的属性提供圆角设置，不再单设圆角矩形入口。

“颜色”标签中的主颜色／副颜色为创建默认值：图形描边取主颜色、填充取副颜色，文字取主颜色。
修改或交换这两种颜色不改变已有对象。图形顶部设置仍可单独调整本次创建的描边与填充。
对象属性的调色弹窗实时更新画布预览；确认只增加一次撤销，取消恢复原色。

“颜色”右侧新增“初始化”标签，按文字、图形、位图保留创建默认参数，创建后显示上一次对象的参数。
这些参数与选中对象属性分开，修改初始化设置不会回写已有对象；位置和尺寸始终使用本次框选。
文字默认开启“字号随框选高度初始化”，依据字体、粗斜体、行距和描边留量计算一行文字的字号；
初始文本很长时仍按文本框宽度换行。关闭开关后使用保存的固定字号。文字字体、内容、行距、
不透明度和描边宽度，图形的填充／描边样式，以及位图的不透明度、Alpha 锁定和采样方式均会保存。
图形初始化参数与顶部创建设置同步，字号自适应只在创建时执行，不会随之后的对象缩放重新计算。
SVG 填充与描边菜单只提供“无”和“纯色”。导入的渐变／图案保留原样，切换纯色后使用撤销恢复；
不再提供“资源（只读）”选项和“重置覆盖”按钮。

三角形通过拖框创建顶点朝上的三顶点多边形，可继续编辑各顶点；创建后选中新对象并返回选择工具。
矩形、椭圆（包括圆形）的 SVG 属性提供“长度”和“宽度”，分别对应对象局部 X／Y 轴的显示尺寸，
不包含描边，与公共对象尺寸使用同一变换和中心；调整尺寸不移动中心，单次操作只提交一条撤销。

SVG 样式只显示对当前对象有作用的控件：矩形、椭圆隐藏端点、连接和斜接限制；
直线保留端点，折线按顶点数显示连接。斜接限制仅在斜接连接时显示。
填充规则只在切换规则会改变填充区域的自交多边形上显示，直线、折线和简单闭合图元隐藏该项。
关闭描边会隐藏描边参数；没有虚线段时隐藏段长度与偏移，保留添加虚线段入口。
不支持直接编辑的复杂 SVG 隐藏图元样式区域，保留可用的对象属性。

基础矢量图元的选中高亮复用创建时的几何轮廓，应用完整对象变换；描边宽度和命中索引的
安全留白不再扩大高亮边框。复杂 SVG 使用变换后的原始边界，文字使用文本框边界。
悬停提示关闭 Qt 的滑出与淡入动画，直接显示。

## 图标与许可

使用 Lucide 线性 SVG 图标，24 像素工具栏、20 像素大纲，颜色区分集合、
栅格、文字和矢量图元。图标随程序本地打包，无联网加载或字体图标依赖。
大纲已移除像素缩略图生成和内容失效逻辑；精灵帧缩略图不受影响。

图标来源：<https://github.com/lucide-icons/lucide/tree/main/icons>，获取日期 2026-10-27。
完整 ISC 许可及派生 Feather 图标的 MIT 许可见
`src/easypicture/resources/icons/LICENSE.txt`，同 SVG 一起嵌入 EXE。
