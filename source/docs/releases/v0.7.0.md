# EasyPicture v0.7.0

Windows x64 单文件版，下载 `EasyPicture.exe` 后直接运行，无需安装 Python。
运行时依赖及许可材料嵌入程序；启动时解包至临时目录，正常退出后清理。

## 主要变化

- 栅格、文字和 SVG 统一为独立对象，集合支持递归混合组织；大纲、画布和属性面板共享选择。
- 属性输入采用统一编辑事务和输入所有权；连续拖动一次提交一条撤销，取消不新增历史。
- 栅格采用局部像素尺寸和非破坏对象变换；变换后可继续绘画，画布裁切保留画布外源内容。
- 增量文档事件、分层缓存和预览调度减少重复刷新与计算。
- 包含像素调色、描边、AI 像素整理，以及现有精灵帧、动画、洋葱皮、Tile 检查和 Atlas 流程。
- 项目目录调整为 `source/`、`archive/`、`release/`；历史构建、测试及报告保留归档。
- 修复 Nuitka 打包下属性控件自身类型注解导致的启动失败。

## 格式变更

`.limg` 仅接受 **schema v5**。v1～v4 工程及旧恢复数据会被明确拒绝，
不提供迁移或转换器，不自动改写原文件。请保留旧版程序及旧工程备份。
工程与资源验证使用结构、解码及像素数据比较，不生成或验证资源摘要。

## 验证范围

- 此版本源码基于已通过的 630 项自动回归测试、Ruff 和 mypy 检查。
- 发布 EXE 验证启动、v5 工程读写、图片导出、SVG 和软件渲染；运行环境移除 Python PATH，Qt 使用 offscreen。
- Windows 原生鼠标、实际拖动手感和硬件 OpenGL 仍待用户人工验收；离屏测试不替代这些验收。

源码中的当前版本号和 EXE 的产品版本均为 0.7.0。
