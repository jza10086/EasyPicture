# EasyPicture v0.8.0

Windows x64 单文件版。下载附件 `EasyPicture.exe` 即可运行，无需安装 Python。

## 栅格独立编辑

- 主画布新增“添加栅格对象”：拖出矩形，创建透明的局部像素区域。
- 选中栅格对象，点击“编辑栅格像素”，在主窗口打开对象专属标签页。
- 像素页按原始像素尺寸提供画笔、橡皮、油漆桶、魔棒、矩形选区和吸管。
- 像素修改实时写回原对象，保留位置、旋转和缩放，共用工程撤销、重做和保存。
- 点击“返回对象画布”继续编排对象；独立精灵帧的栅格编辑写入对应嵌入文档。
- 栅格范围以虚线矩形显示，跟随变换预览，不进入图片导出。

## 创建与生命周期修复

- 新建图形、文字和栅格对象沿用所选对象的父集合；选中集合时插入该集合。
- 根对象的新兄弟仍位于根层，连续创建不再生成多余集合。
- 创建工具持续创建独立对象；已有 SVG 通过显式矢量内容编辑模式修改。
- 切换页面取消未完成笔划，删除对象关闭对应栅格标签，继承集合锁定。
- 修复页面切换时工具状态读取旧文档选择，以及关闭时的订阅和历史清理问题。

## 格式与验证

- `.limg` 继续使用 schema v5；栅格编辑标签属于工作区状态，不改变工程格式。
- Ruff、mypy（138 个源文件）及 641 项自动测试通过。
- 新 EXE 发布前独立验证应用启动、工程读写、图片导出、SVG 和软件渲染。
- 验证使用结构、解码和像素数组比较，不进行文件或资源哈希校验。
- 自动交互采用离屏 Qt 和虚拟指针。Windows 原生鼠标、拖动手感及硬件 OpenGL 仍待人工验收。

源码版本及 EXE 产品版本：0.8.0。
