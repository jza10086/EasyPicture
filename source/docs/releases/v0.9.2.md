# EasyPicture v0.9.2

Windows x64 单文件版。下载附件 `EasyPicture.exe` 即可运行，无需安装 Python。

## 统一对象属性

- 栅格、文字、SVG 共用对象变换区，移除 SVG 和文字面板中重复的位置、旋转及中心字段。
- 位置 X/Y 表示对象中心的画布坐标；中心偏移使用局部坐标。修改中心不移动内容，G/S/R 与高亮使用同一中心。
- SVG 几何尺寸不再包含描边或渲染留白。文字排版框保留独立的内容尺寸设置。
- 中心随对象变换移动，撤销／重做精确恢复原中心；属性预览同步关联字段，非法缩放不会提交。

## 高亮与动态数值范围

- 全局设置中的选区颜色／粗细替换为高亮边框颜色／粗细，统一用于对象、选区及创建／编辑轮廓。
- 对象中心显示圆形标记，默认半径 7.5 px，不随画布缩放；颜色默认跟随边框，可独立调整半径与颜色。
- 空间字段软范围随当前编辑画布变化，例如 1920×1080 画布的 X/Y 分别为 ±1920／±1080。
- 尺寸、对象缩放、圆角、描边和虚线等采用对应画布或对象几何的动态范围；仍允许手动输入超出软范围的合法数值。

## 全局／局部变换

- 顶部新增全局／局部坐标选择，G/S/R 操作时显示坐标轴。
- X/Y 首次约束当前坐标方向，同键再次切换另一坐标系，第三次解除约束；L 可切换全局／局部方向。
- 局部轴取操作开始时活动对象的方向，多选共用该方向；二维旋转始终在画布平面内绕共同中心进行。
- 保持单次操作单条撤销，取消操作清除预览和轴线。

## 验证与已知限制

- Ruff、mypy（140 个源文件）通过；446 项单元测试、217 项 UI 测试和 5 项 CLI 集成测试分进程通过，共 668 项。
- 源码及发布 EXE 检查启动、工程读写、图片导出、SVG 和软件渲染。
- 当前 Windows / PySide6 6.11.1 环境下，合并测试进程或启用 JUnit XML 收集可能触发 Qt 回收堆异常；默认分进程运行并保留文本日志，该环境问题仍未解决。
- 未计算或比较文件／资源哈希，未执行 Windows 原生鼠标操作。实际交互手感、高 DPI 和硬件 OpenGL 待用户人工验收。
- `.limg` 仍仅接受 schema v5。

源码版本和 EXE 产品版本统一为 0.9.2。
