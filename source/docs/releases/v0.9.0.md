# EasyPicture v0.9.0

Windows x64 单文件版。下载附件 `EasyPicture.exe` 即可运行，无需安装 Python。

## 工作区与属性布局

- 新增“矢量编辑／位图编辑”工作区入口，分别显示对象／矢量工具和像素工具。
- 顶部显示当前工具设置，“详细设置”展开复杂参数；切换工具不再抢占右侧对象属性。
- 右上对象大纲改用类型图标，取消画面内容缩略图；像素修改不再触发大纲缩略图重绘。
- 右下整合对象不透明度、锁定、变换和内容属性；原颜色面板合并为属性区内的颜色标签。
- 采用本地打包的 Lucide SVG 图标，完整 ISC／MIT 许可证随 EXE 内嵌，无需联网加载。

## 导航与选择

- 滚轮直接以指针位置为中心缩放，中键／Space 拖动继续平移。
- 对象选择工具新增“忽略透明像素”开关，偏好持久保存，默认关闭，方便选中空栅格区域。
- 开启后点选穿过透明栅格、SVG 空心区域和文字空白；变换后的栅格通过局部像素坐标判断命中。
- 框选继续按对象范围选择，不受该开关影响。

## 修复与验证

- 修复窗口销毁后状态提示计时器和颜色取样事件过滤器访问已删除控件的问题。
- 修复窄窗口下精灵面板挤占右侧属性区的布局问题。
- 646 项自动测试、Ruff 和 mypy（140 个源文件）通过。
- 发布 EXE 独立验证启动、工程读写、图片导出、SVG 和软件渲染。
- `.limg` 继续使用 schema v5；旧面板布局重新使用本次默认布局，工程内容不迁移。
- 验证不计算或比较文件／资源哈希，不执行 Windows 原生鼠标操作。
- 原生滚轮与拖动手感、多显示器 DPI 和硬件 OpenGL 仍待用户人工验收。

源码版本和 EXE 产品版本统一为 0.9.0。
