# EasyPicture v0.9.1

Windows x64 单文件版。下载附件 `EasyPicture.exe` 即可运行，无需安装 Python。

## 对象交互

- 新增 Blender 风格的 G 移动、S 缩放、R 旋转；G／S 支持 X／Y 轴约束，Shift 精调。
- 左键或 Enter 确认，Esc／右键取消；一次变换只产生一条撤销，窗口失活取消未完成操作。
- 在画布和大纲中按 Del 删除选中对象；文本编辑中的 Delete 及位图油漆桶的 G 保持原有作用。
- 统一“创建对象”按钮及矢量／位图二级菜单，Shift+A 打开同一菜单。创建对象沿用当前对象的父集合。
- 框选也遵循“忽略透明像素”：透明栅格、空心图形内部和文字空白不会仅因包围盒相交而被选中。
- 基础矢量对象的高亮沿创建时的几何轮廓绘制，正确应用旋转和缩放，不再包含描边及命中留白。

## 属性与界面

- 取消悬停提示的滑出与淡入动画，直接显示。
- 缩小拖动软范围：坐标和平移 ±256 px、旋转 ±180°、缩放 0.1～4 倍，另调整半径、描边及虚线范围。
- 仍允许手动输入超出软范围、符合硬范围的数值与表达式。
- 修复窗口销毁后延迟布局回调仍可能访问已删除控件的问题。
- 当前测试和基准脚本集中到 `tmp/test/`，历史验收材料保留。

## 验证与已知限制

- Ruff、mypy（140 个源文件）通过；445 项单元测试、209 项 UI 测试和 5 项 CLI 集成测试分组通过，共 659 项。
- 发布 EXE 独立检查启动、工程读写、图片导出、SVG 和软件渲染。
- 当前 Windows / PySide6 6.11.1 环境下，合并测试进程或启用 JUnit XML 收集可触发 Qt 回收堆异常；未修改的 v0.9.0 也能复现。默认分组运行并保留文本日志，没有跳过用例；该聚合运行问题仍未解决。
- 验证不计算或比较文件／资源哈希，不执行 Windows 原生鼠标操作。原生交互手感、DPI 和硬件 OpenGL 仍待用户人工验收。
- `.limg` 仍仅接受 schema v5。

源码版本和 EXE 产品版本统一为 0.9.1。
