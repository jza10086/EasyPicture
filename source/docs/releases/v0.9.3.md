# EasyPicture v0.9.3

下载 `EasyPicture.exe` 即可在 Windows x64 上运行。

- 按 Shift+A 可拖框创建三角形，随后可单独编辑三个顶点。图形、文字和位图对象创建后会自动选中，并返回选择工具。
- 新的“初始化”标签按对象类型保存创建参数。文字默认按框选高度计算字号，也可指定固定字号。
- 主颜色用于新图形的描边和文字，副颜色用于图形填充。编辑对象颜色时画布实时预览，确认只产生一次撤销，取消恢复原色。
- 矩形和椭圆可在 SVG 属性中直接调整长宽，保留中心和旋转。普通矩形可设置圆角，创建菜单已合并重复的圆角矩形入口。
- SVG 属性按当前图形显示。矩形和椭圆隐藏端点和连接，折线隐藏填充规则，自交多边形仅在规则会改变填充区域时显示该项。
- G/S/R 变换时参考轴原点跟随预览，局部轴跟随对象方向，多选共同中心也随预览移动。

本次修改在开发期间通过了相关离屏测试。发布打包时跳过了 EXE 冒烟测试。
