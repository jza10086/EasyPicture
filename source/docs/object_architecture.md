# 统一对象编辑架构

## 权威状态与选择

`Document.nodes` 是唯一权威节点树。根和集合中均可包含 `Collection`、
`RasterObject`、`TextObject`、`SvgObject`；`layers` 是派生查询，不能独立增删。
UUID 注册表、父索引、空间索引由文档命令维护。集合没有矩阵，显隐、锁定和
不透明度逐级继承；绘制从数组头到尾，大纲反向显示，顶部对象在前。
透明度穿透到叶对象，不进行隔离组混合。

`SelectionCoordinator` 保存工作区选择，键为工程会话 ID 与编辑文档 ID。
`SelectionState` 包含多选、活动对象、内容编辑目标和编辑模式。选择不增加文档
内容版本，不进入撤销栈；关闭工程清理对应记录。独立帧使用自己的文档和命令历史。
对象选择与文档像素选区互相独立。选择对象不会自动切换工具。

`ObjectCommandService` 是创建、删除、复制、移动、公共属性和批量矩阵操作的入口，
与 `DocumentCommandService` 共用一个撤销栈。集合操作展开为去重的后代对象；
任一目标不可编辑时整个操作拒绝。结构命令复用未变化实例和 COW Tile，
不重建无关缩略图；复制分配新 UUID，第一次像素写入即分离。

## 输入和提交

`PropertyBinding` 描述字段规格、读取、同步和校验；
`PropertyEditSession` 捕获工程、编辑文档、对象和依赖版本，执行
`begin → preview → commit/cancel`。预览保存在协调器中，不提前写文档。
释放或确认只提交一次，取消和无变化均为零条历史。

`InteractionCoordinator` 负责跨控件输入所有权，不替代整数／浮点控件内部状态机。
文本字段通过焦点编辑会话合并输入；切换字段先结束合法文本，非法最终文本恢复原值。
模型回写通过同步接口推迟到活动会话结束，不重填活动文本，不先切空属性页。
对象变换、文字、SVG、透明度使用同一事务；填充／描边、颜色弹窗和预览应用／取消
按钮由 `property_blocks.py` 组合复用。模态结束释放所有权，不重放原画布事件。

Enter 确认，Esc／右键取消，消费相应释放事件。活动拖动不能被选择或工具命令抢占。
文档切换、目标删除、依赖版本冲突和窗口失活取消未完成交互。对象拖动订阅完成的
文档版本事件，目标失效时立即清预览并释放所有权。

指针操作只通过 `PointerBackend`。生产后端管理捕获、隐藏和位置恢复；
offscreen/minimal 使用虚拟后端。测试禁止真实指针后端、系统位置设置和原生捕获。

## 坐标和像素

当前主窗口采用对象画布与独立栅格像素标签页，页面契约、局部选区和创建集合规则见
[栅格编辑页](raster_editor.md)。以下坐标服务仍用于领域命令和渲染，主画布不直接执行画笔笔划。

对象矩阵为二维仿射矩阵 `[a,b,c,d,tx,ty]`，按
`x'=a*x+c*y+tx, y'=b*x+d*y+ty` 解释。栅格保留整数基准位置 `origin`，
世界矩阵为 `transform.then(translation(origin))`；两者共同定义一个局部到文档映射。
集合不参与矩阵继承。

`RasterMapping` 在笔划开始捕获目标、局部尺寸和矩阵。画笔半径以对象像素计，
光标绘制变换后的轮廓。笔划、填充、取样、选区覆盖、图形栅格化、颜色处理、
调色板、描边和 AI 整理统一使用局部网格；合并取样先合成权威文档再映射回来。
选区覆盖用最近邻或双线性采样；无选区时允许写入对象范围内的画布外像素。

对象移动、旋转、缩放、翻转只变矩阵。画布裁切／缩小／透明修剪只改变输出范围，
不裁源 Tile；图像缩放同步画布和对象矩阵。对象分辨率调整明确重采样并补偿矩阵，
对象局部画布调整明确扩展／裁去像素。应用对象变换按文档分辨率栅格化，保留位置，
重置矩阵；像素四角／透视和浮动选区仍属于重采样操作，均可一次撤销恢复。

变换拒绝不可逆和超限值：行列式绝对值至少 `1e-8`，线性系数绝对值不超过
1024，平移不超过 1,000,000，逆矩阵线性系数不超过 1,000,000。
非法输入保留上一次有效预览。局部尺寸与输出画布上限均为 8192。

独立帧保持现有固定精灵单元输出尺寸；其对象局部画布、像素分辨率、内容和矩阵可独立编辑。
修改整个精灵单元输出尺寸在父工程的精灵设置中执行，不会误把局部对象操作应用到父工程。

## 刷新规则

领域命令同步完成；`DocumentChangeSet` 在事务结束时发布，包含对象字段、
变化 Tile、结构操作和旧／新边界。版本分为内容、样式、变换、结构、元数据和像素选区。
画布帧请求和精灵缩略图任务合并，标签按 ID 增量同步，大纲按行增删／移动。
大纲 UUID 到行索引独立维护，选择和改名不递归搜索整树。

| 变化 | 派生更新 |
| --- | --- |
| 名称 | 对应大纲文字、必要标题；保留源图与缩略图 |
| 对象选择 | 高亮、属性目标、工具可用性；不改内容版本 |
| 锁定／Alpha 锁定 | 标记及权限；保留源图缓存 |
| 显隐／不透明度 | 显示遍历及相关缩略图；保留源像素 |
| 局部像素 | 变化 Tile、依赖预览与受影响帧 |
| 矩阵 | 边界、空间索引、显示参数；保留源像素 |
| 增删／排序 | 对应模型行、祖先缩略图与绘制顺序 |
| 输出画布尺寸 | 输出边界、选区派生缓存；保留未改变的源 Tile |

完整模型重置仅用于更换文档。跨文档和已删除目标的迟到事件被消费者拒绝。
主窗口负责组合，选择、输入事务、对象命令、渲染缓存、颜色预览和后台调度分别由公共组件管理。

## 缓存、调度和输出

软件画布、OpenGL、导出、缩略图和合并取样遵循相同的递归绘制顺序。
编辑视图以 25% 不透明度显示画布外内容，最终图片严格限制在输出画布。
SVG 导出保留文字／SVG 矩阵和顺序，栅格以局部 PNG 加矩阵嵌入，并在画布边界裁切。

SVG 解析和文字排版按内容描述复用，每线程各限制 2048 项、估算 32 MiB；
CPU Tile 源图缓存预算 256 MiB，GPU 页预算 512 MiB，大纲缩略图各限 512 项。
Tile 使用运行期递增 generation，避免撤销和替换内容的局部版本重用导致命中旧缓存。
显示遍历结果是有界派生缓存，不保存第二份可编辑状态。关闭／切换画布释放相关资源。
空间索引使用固定网格，边界包括描边和抗锯齿余量。

`PreviewScheduler` 每会话最多一个运行请求和一个最新待处理请求；
结果同时匹配工程、编辑文档、目标、依赖版本及 generation。
颜色、描边、AI、调色板提取、重图形预览和 Tile 工作区共享调度协议。
预览队列默认单线程，保存／恢复使用独立队列。

大图常用颜色调整先生成最长边 1024 的预览，再计算完整结果。
低分辨率结果明确标为不可应用；抖动、精确描边和 AI 整理保持完整结果原子替换。
点击应用冻结参数，等待最新完整结果；取消仍可用，迟到结果不能写入已关闭目标。
计算源图采样直接从 Tile 提取，不先分配整张 4096² 源图。

## 对象中心与变换坐标

栅格、文字、SVG 共享 `domain/object_operations.py` 中的几何边界、中心和局部轴定义。SVG 的几何尺寸取原始图元，不使用描边或渲染裁剪边界。SVG 面板不再提供另一套对象变换字段，只保留内容几何、圆角、顶点与绘制样式。

`transform_pivot=None` 表示自动几何中心；显式中心沿用工程中画布坐标的保存字段，属性区通过对象逆矩阵转换为局部中心偏移。变换命令同时保存变换前后的中心，保证移动、旋转、缩放、撤销和重做后中心仍跟随对象，重复撤销不累计浮点误差。多选的共同中心属于工作区状态，不改变每个对象的中心定义。

顶部全局／局部坐标选择器决定 G/S 的轴方向。局部轴固定为操作开始时活动对象的方向（选中集合时取其首个后代对象），多选共用该方向。X/Y 首次约束当前方向，同键再次切换另一方向，第三次解除约束；L 可在操作中切换方向。此按键循环参考 [Blender 轴约束文档](https://docs.blender.org/manual/en/5.2/scene_layout/object/editing/transform/control/axis_locking.html)。二维 R 始终在画布平面绕共同中心旋转，全局／局部的平面相同。坐标轴显示原点与多选共同中心圆跟随有效预览移动；局部轴显示方向随预览旋转／缩放，全局轴保持世界方向，轴线屏幕长度不变。手势计算仍使用操作开始时的参考，避免连续预览累计偏移。确认只生成一个命令，取消清除预览和坐标轴。

全局高亮边框设置同时用于选区、对象边界和创建／编辑轮廓。中心圆按屏幕逻辑像素绘制，不随画布缩放；默认半径 7.5 px，颜色默认跟随边框，也可独立设置。高亮不参与导出和文档历史。
