# UI 数值范围策略

空间类数值控件的公共软范围和硬范围集中定义在
`src/easypicture/ui/numeric_ranges.py`。

- 常用画布与对象尺寸的软上限为 `4096 px`。
- 文档、变换、文字框和 SVG 对象仍可通过文本输入达到领域模型允许的硬上限。
- 坐标、旋转、字体、描边和虚线使用适合常见操作的软范围，同时保留原有合法硬范围。
- 圆角等依赖其他属性的参数采用动态范围；圆角不得超过对应边长的一半。
- 百分比、颜色通道、容差、导出质量及颜色调整参数属于算法固有限制，继续在对应模块定义。
- 枚举下拉框在收起状态下不消费鼠标滚轮，滚轮交由外层 Dock 或属性面板处理。

新增空间属性时应优先复用集中范围；只有领域算法自身决定的边界才应在功能模块中单独声明。

对象变换面板也统一使用此策略，不再把 ±32768 同时作为拖动与文本范围：

| 参数 | 拖动软范围 | 手动输入范围 |
| --- | --- | --- |
| 坐标、平移、共同中心 | −256～256 px | −32768～32768 px |
| 旋转 | −180～180° | −36000～36000° |
| 对象缩放倍数 | 0.1～4 | −100～100（零或不可逆变换拒绝） |
| 圆角／半径 | 0～128 px | 由对象几何合法范围决定 |
| 描边宽度 | 0～32 px | 0～8192 px |
| 虚线长度／偏移 | 0～64／−64～64 px | 0～8192／−8192～8192 px |

软范围仅限制拖动，单击后可输入超出软范围的合法值与表达式；Shift 使用更细的拖动步长。

P10E 的目标色数与像素描边宽度也使用集中配置：

| 参数 | 软范围 | 硬范围 | 默认值 |
| --- | --- | --- | --- |
| `PALETTE_COLOR_COUNT_RANGE` | 1～64 | 1～256 | 16 |
| `PIXEL_OUTLINE_WIDTH_RANGE` | 1～16 px | 1～64 px | 1 px |
| `AI_PALETTE_COLOR_COUNT_RANGE` | 1～64 | 1～256 | 32 |
| `AI_PIXEL_BLOCK_RANGE` | 1～64 px | 1～4096 px | 8 px |

AI 处理网格对齐范围随块大小动态变为 `0～块大小−1`，通过 `syncPropertyRange()` 同步。宽高联动只对另一个输入框调用 `syncValue()`，不得中断正在拖动的字段。Alpha 阈值 1～255、默认 128；抖动强度 0～100%、默认 35%。

描边 Alpha 阈值由算法限制为 1～255，默认 128；颜色首次取当前前景色，之后恢复本机最后使用值。

右键“设为默认值”恢复预设参数。`UiNumericRange.default_value` 集中描述通用空间预设（尺寸 32、半径 16、描边 1、斜接 4、字号 32）；圆角单独使用 0。Tile、画笔和洋葱皮等使用其参数 dataclass 的默认值，避免误把上次保存的参数当作默认。控件支持独立 `setDefaultValue()`，不改变当前值或活动交互。
