# 对象架构：用户人工验收

状态：**待用户人工验收**。本次自动化仅使用离屏 Qt 和虚拟指针，
没有操作 Windows 原生鼠标，也没有验证鼠标捕获、屏幕边缘、设备或长期手感。
OpenGL 硬件路径在当前离屏环境未覆盖；请分别使用软件与可用的 OpenGL 后端检查。

## 连续输入

- 在整数、浮点、文字和 SVG 属性之间连续操作；长时间拖动不应被面板刷新打断，
  顶部栏与侧栏的相同属性保持一致，松开只撤销一次。
- 拖动跨出控件、窗口和屏幕边缘，使用 Shift 精调；完成后光标显示、位置和捕获恢复。
- 文字选择、输入、Enter、切换其他字段；一次编辑一条历史，非法值恢复并提示。
- 拖动时分别用 Esc、右键、窗口失活和切换工程取消；释放按键不应传给画布或创建新对象。
- 打开颜色或几何弹窗后确认／取消；弹窗关闭后不应继续原来的画布拖动。

## 对象和大纲

- 新建混合集合并嵌套；检查类型标记、显隐、锁定、重命名、展开状态和滚动位置。
- Shift／Ctrl 多选，跨集合拖放和排序；选中集合及其子对象时不重复变换。
- 搜索时仅过滤显示，拖放排序禁用；清空搜索恢复原顺序。
- 画布点选／框选与大纲一致；选择文字或 SVG 不自动切换当前工具。
- 移动／旋转／缩放多个对象，修改共同中心；撤销一次恢复全部。
  含锁定目标时整体拒绝，解除祖先锁定后恢复编辑。
- 使用 Shift+A 分别创建文字、矩形、圆、折线／多边形；每次都是独立对象，
  创建后选中新对象并切回选择工具，再次使用 Shift+A 创建。顶点编辑和复杂 SVG 整体变换正常。

## 栅格和输出

当前 UI 的入口与分工以[栅格编辑页验收](raster_editor.md#人工验收)为准。
像素操作在独立栅格标签页进行，主画布用于对象变换与输出范围操作。

- 对栅格对象平移、旋转、非等比缩放和翻转后进入独立像素页绘画；光标范围与落笔一致，
  画笔尺寸按对象像素解释，撤销恢复内容但不意外重置矩阵。
- 在文档选区边缘、画布外内容、透明锁定下使用笔刷、橡皮、桶、魔棒、吸管、
  栅格图形、颜色调整、描边和 AI 整理；检查合并取样和最近邻／平滑边缘。
- 缩小画布再扩大，原内容重新可见；画布外仅在编辑视图弱化显示，不进入 PNG、Atlas 或帧输出。
- 对比图像缩放、对象像素分辨率、局部像素画布裁切和应用对象变换；每项撤销都应完整恢复。
- 检查浮动选区和像素透视；它们会明确重采样，与对象矩阵变换区分。

## 工作区、预览和长时运行

- 多工程、源图、独立帧、动画与 Tile 反复切换；选择、缩放、展开和撤销历史不串工程。
- 检查动画播放、洋葱皮、调色板、Atlas 和自动恢复。
- 大图快速连续改参后立即应用；只能提交最后参数的完整结果。
  等待计算时取消或关闭工程，迟到结果不能再次出现。
- 关闭大型工程后继续新建与编辑，观察资源释放及长时间响应。
- 使用新的 `.limg` 保存后重新打开；旧格式只显示拒绝说明，原文件不被改写。

遇到问题请记录工程／帧、后端、工具、所选对象类型、操作顺序以及期望／实际结果。
自动测试通过不代表上述人工验收已经完成。

- 高亮边框颜色／粗细、中心圆颜色／半径：检查高 DPI 下的实际观感及不同缩放倍率；默认半径 7.5 px。
- 旋转对象后比较 G X 与 G X X、S X 与 S X X，检查全局／局部轴和多选共同中心；Esc／右键取消后不应残留轴线。
- 切换 1920×1080 与其他尺寸画布，检查 X/Y 动态拖动范围及手动输入超出软范围后的连续拖动手感。
